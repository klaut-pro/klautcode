ชุดโครงการชุมชนที่สร้างขึ้นบน Klautcode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Klautcode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-klautcode](https://github.com/awesome-klautcode/awesome-klautcode) และ [klautcode.cafe](https://klautcode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
